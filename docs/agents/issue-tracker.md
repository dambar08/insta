# Issue tracker: GitHub

Issues and specs live in GitHub Issues for `dambar08/insta`. Use the `gh` CLI.

- Create issues with `gh issue create`; read them with `gh issue view`.
- List and filter issues with `gh issue list`.
- Comment, label, and close issues with the corresponding `gh issue` commands.
- Use GitHub sub-issues and native issue dependencies for relationships when available; otherwise record the relationship in the issue body.
- Verify the repository with `gh repo view` before creating issues. File issues only in this repository.
- Pull requests are not a request surface for triage.
